# Dark Souls 2: Scholar of the First Sin Cheat Sheet

Modern checklist for DS2: SOTFS, forked from
[xenevel's original](https://github.com/xenevel/dark-souls-2-sotfs-cheat-sheet).

**Live:** https://m-d3bug.github.io/ds2-companion/

## What's new

- **Search + filter chips** across every tab. Tabs with hidden matches show a count.
- **Automatic item badges** (boss, bonfire, NPC, Estus, key, branch, lockstone, vessel, ascetic, covenant, gesture, secret, memory) derived from each row's own text and links.
- **Progress bars** per section, overall pill in the toolbar.
- **Hide Completed** and **Collapse All** toggles.
- **Multiple character profiles**, saved in your browser.
- **Dated JSON backups** (`ds2-backup-YYYYMMDD-HHmm.json`), portable across devices.
- **Dark fantasy theme**, responsive, with a print stylesheet.
